Bash / Shell: Tự Động Hóa & Quản Trị Hệ Thống Dòng Lệnh

Bash (Bourne Again SHell) là giao diện dòng lệnh mặc định trên hầu hết hệ thống Linux/Unix và macOS. Nó là vũ khí tối thượng của lập trình viên và kỹ sư DevOps để tự động hóa tác vụ, quản lý máy chủ, cấu hình CI/CD và vận hành ứng dụng trên môi trường thực tế.

Tại sao Bash & Dòng lệnh là kỹ năng bắt buộc?

Dòng lệnh đem lại quyền kiểm soát tuyệt đối hệ điều hành với hiệu năng cao nhất. Bất kỳ kỹ sư phần mềm, quản trị hệ thống hay DevOps nào cũng cần Bash để triển khai ứng dụng, tự động hóa backup và gỡ lỗi máy chủ từ xa.

Các nhóm lệnh & Kỹ năng Bash trọng tâm

01

Lệnh Điều hướng & Quản lý File

Các lệnh cốt lõi: ls -la, cd, mkdir -p, cp -r, mv, rm -rf, chmod, chown, phân quyền tập tin và thư mục.

02

Xử lý Luồng Dữ liệu & Văn bản

Ống dẫn Pipe (|), Redirect (>, >>), tìm kiếm lọc chuỗi với grep, awk, sed, cat, tail -f, find.

03

Lập trình Shell Script & Tự động hóa

Biến môi trường, vòng lặp for/while, câu lệnh điều kiện if/else, hàm (functions), cấu hình Cronjob định kỳ và tự động hóa CI/CD.

Ví dụ "Kịch bản Sao lưu & Giám sát Hệ thống Tự động (backup_deploy.sh)"

Script kiểm tra dung lượng ổ đĩa, nén thư mục và đẩy log an toàn.

deploy.sh
BASH
#!/usr/bin/env bash
# Script tự động kiểm tra tài nguyên và triển khai bản build
set -euo pipefail

APP_DIR="/var/www/devportal"
BACKUP_DIR="/data/backups"
TIMESTAMP=$(date +"%Y%m%d_%H%M%S")
DISK_THRESHOLD=85

echo "===> [1/3] Kiểm tra dung lượng phân vùng hệ thống..."
CURRENT_USAGE=$(df / | awk 'NR==2 {print $5}' | tr -d '%')
if [ "$CURRENT_USAGE" -gt "$DISK_THRESHOLD" ]; then
echo "⚠️ CẢNH BÁO: Dung lượng ổ đĩa vượt quá ${DISK_THRESHOLD}% (Hiện tại: ${CURRENT_USAGE}%)!"
exit 1
fi
echo "===> [2/3] Tiến hành nén dữ liệu phiên bản: v_${TIMESTAMP}..."
mkdir -p "$BACKUP_DIR"
tar -czf "${BACKUP_DIR}/devportal_${TIMESTAMP}.tar.gz" -C "$APP_DIR" .
echo "✅ Bản sao lưu đã lưu tại: ${BACKUP_DIR}/devportal_${TIMESTAMP}.tar.gz"
echo "===> [3/3] Tải và kích hoạt dịch vụ mới..."
systemctl restart nginx && pm2 reload all
echo "🚀 Triển khai thành công vào lúc $(date)!"
