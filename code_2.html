}

Mục tiêu bài học

Trong thực tế, các API nội bộ thường trả về các object chứa dữ liệu nhạy cảm (như password, token). Việc truyền trực tiếp dữ liệu này xuống frontend là một lỗ hổng bảo mật nghiêm trọng.

check_circle

Yêu cầu

  • Hoàn thành hàm processUserData(rawData).
  • Loại bỏ thuộc tính passwordHash và socialSecurityNumber khỏi object trước khi return.
