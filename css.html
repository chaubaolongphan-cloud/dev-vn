Cascading Style Sheets

CSS3: Định Hình Giao Diện & Phong Cách Web

CSS (Cascading Style Sheets) là ngôn ngữ quy định cách hiển thị các phần tử HTML trên trình duyệt, từ màu sắc, kiểu chữ, bố cục linh hoạt (Flexbox, Grid) đến hiệu ứng chuyển động mượt mà (Animations & Transitions).

Tại sao CSS quan trọng?

CSS biến cấu trúc HTML thô sơ thành trải nghiệm người dùng hiện đại, tương thích đa thiết bị (Responsive Design) và tối ưu hóa hiệu suất hiển thị mà không cần tải thêm mã logic phức tạp.

Các nhóm thuộc tính CSS nền tảng

01

Bố cục & Hiển thị

Display, Flexbox, CSS Grid, Position (Relative, Absolute, Sticky), Float & Clear.

02

Kiểu dáng & Màu sắc

Color, Background, Typography (Font, Line-height), Box-Model (Margin, Padding), Borders.

03

Hiệu ứng & Nâng cao

Transitions, Keyframes Animation, Media Queries (Responsive), Biến CSS (Variables).

Ví dụ: "CSS Cơ bản & Hiện đại"

Xây dựng thẻ giao diện mượt mà với Flexbox, Biến CSS và hiệu ứng Hover.

style.css
CSS 
/* Tạo thẻ Card hiện đại với Flexbox & Biến CSS */
:root {
  --primary-color: #64ffda;
  --bg-card: #0f172a;
}

.card-container {
  display: flex;
  justify-content: center;
  align-items: center;
  padding: 24px;
  background-color: var(--bg-card);
  border-radius: 12px;
  border: 1px solid rgba(100, 255, 218, 0.2);
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card-container:hover {
  transform: translateY(-4px);
  box-shadow: 0 10px 25px rgba(0, 0, 0, 0.5);
}
