TRI THỨC THỰC CHIẾN

5 Vấn Đề Lập Trình Thường Gặp & Cách Xử Lý Nhanh

Cập nhật hàng tuần theo báo cáo cộng đồng
NGUYÊN NHÂN GÂY LỖI:

Bạn đang cố gắng truy cập thuộc tính (property) hoặc gọi phương thức của một biến đang có giá trị undefined hoặc null, thường xảy ra khi gọi API bất đồng bộ chưa có dữ liệu trả về.

HƯỚNG DẪN KHẮC PHỤC NHANH:
  • Sử dụng toán tử Optional Chaining (?.): Thay vì viết user.profile.name, hãy dùng user?.profile?.name để tránh throw exception.
  • Sử dụng giá trị mặc định bằng toán tử Nullish Coalescing (??): Cung cấp fallback giá trị rỗng khi dữ liệu chưa tải xong.
  • Khởi tạo State an toàn với cấu trúc mặc định trước khi nhận phản hồi từ API.
NGUYÊN NHÂN GÂY LỖI:

Python Interpreter đang chạy không tìm thấy thư viện trong môi trường hiện tại, do bạn cài đặt trên Python toàn cục nhưng lại chạy chương trình trong Virtual Environment (venv) hoặc ngược lại.

HƯỚNG DẪN KHẮC PHỤC NHANH:
  • Kiểm tra đường dẫn môi trường đang kích hoạt và cài gói thư viện tương ứng qua lệnh pip của chính môi trường đó.
  • Đảm bảo đã thêm tệp đánh dấu gói package __init__.py nếu đang import module tự tạo từ thư mục nội bộ.
  • Kiểm tra biến môi trường PYTHONPATH đã bao gồm thư mục gốc của dự án.
NGUYÊN NHÂN GÂY LỖI:

Cơ chế bảo mật Same-Origin Policy của trình duyệt chặn các request HTTP từ domain này sang domain khác nếu máy chủ API không phản hồi header Access-Control-Allow-Origin tương thích.

HƯỚNG DẪN KHẮC PHỤC NHANH:
  • Cách chuẩn nhất: Cấu hình middleware CORS ở phía Backend (Node.js, Spring, FastAPI...) cho phép domain client truy cập.
  • Trong quá trình phát triển (Local Dev): Cấu hình Proxy trung gian trong file cấu hình Vite/Webpack để chuyển tiếp request cùng domain local.
  • Không tắt bảo mật trình duyệt trên máy khách vì không phải giải pháp bền vững cho môi trường Production.
NGUYÊN NHÂN GÂY LỖI:

Hai nhánh bạn đang cố gắng gộp (thường là repo local mới tạo và repo remote trên GitHub có sẵn README) không có chung commit khởi tạo ban đầu.

HƯỚNG DẪN KHẮC PHỤC NHANH:
  • Sử dụng cờ xác nhận hợp nhất lịch sử không liên quan: Bổ sung tham số xác thực --allow-unrelated-histories khi thực hiện kéo mã về (git pull).
  • Tiến hành giải quyết xung đột (conflict) phát sinh nếu có, rồi tạo commit hợp nhất mới để đồng bộ hai cây lịch sử.
NGUYÊN NHÂN GÂY LỖI:

Tải toàn bộ tập dữ liệu cực lớn (hàng triệu bản ghi) vào một mảng duy nhất trong RAM, hoặc tạo Closure/EventListener liên tục bên trong vòng lặp mà không giải phóng tham chiếu.

HƯỚNG DẪN KHẮC PHỤC NHANH:
  • Chuyển sang cơ chế Streaming Data hoặc Paging/Cursor-based Pagination thay vì fetch toàn bộ bảng dữ liệu.
  • Sử dụng Generator function hoặc Iterators để xử lý tuần tự từng item thay vì giữ nguyên mảng tĩnh khổng lồ.
  • Đảm bảo dọn dẹp các biến tham chiếu toàn cục sau khi kết thúc chu trình xử lý batch.
