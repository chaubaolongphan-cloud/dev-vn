HTML5: Bộ Xương Của Web

HTML (HyperText Markup Language) là ngôn ngữ đánh dấu tiêu chuẩn để tạo ra các trang web. Nó mô tả cấu trúc của một trang web bằng cách sử dụng các thẻ markup. HTML là nền tảng cốt lõi của mọi ứng dụng web, định hình nội dung trước khi CSS và JavaScript thêm phong cách và tính tương tác.

lightbulb

Tại sao HTML quan trọng?

Mặc dù không phải là một ngôn ngữ lập trình thuần túy, việc nắm vững HTML ngữ nghĩa (Semantic HTML) là rất quan trọng cho SEO, khả năng truy cập (Accessibility - a11y) và hiệu suất trang web. Nó giúp trình duyệt và công cụ tìm kiếm hiểu rõ nội dung của bạn.

Lộ trình học tập HTML

looks_one

Cơ bản

  • check Cấu trúc tài liệu cơ bản (html, head, body)
  • check Heading & Paragraphs (h1-h6, p)
  • check Danh sách (ul, ol, li)
  • check Liên kết & Hình ảnh (a, img)
looks_two

Trung cấp

  • check Bảng dữ liệu (table, tr, td)
  • check Biểu mẫu & Inputs (form, input, select)
  • check HTML Ngữ nghĩa (Semantic HTML5)
  • check Phân chia layout (div, span)
looks_3

Nâng cao

  • check Thuộc tính Data & Tùy chỉnh (data-*)
  • check Tích hợp Đa phương tiện (audio, video)
  • check Khả năng truy cập (ARIA attributes)
  • check Web Storage & APIs tích hợp

Ví dụ "Hello, World!"

Cấu trúc tài liệu HTML5 tối giản nhất để hiển thị nội dung cơ bản trên trình duyệt.

HTML 
<!DOCTYPE html>
<html lang="vi">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Trang đầu tiên của tôi</title>
</head>
<body>
    <h1>Hello, World!</h1>
    <p>Chào mừng bạn đến với thế giới lập trình Web.</p>
</body>
</html>
