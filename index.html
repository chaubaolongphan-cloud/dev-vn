Web Lập trình VN

Nền tảng học tập và chia sẻ kiến thức chuyên sâu dành riêng cho cộng đồng kỹ sư phần mềm Việt Nam. Khám phá tài liệu, code snippets và thực hành trực tiếp.

Bắt đầu ngay play_circle
main.js 

import { Community } from '@vn/dev';

const developer = new Developer({
  passion: true,
  location: 'Vietnam'
});

function init() {
  if (developer.isReady()) {
    Community.join(developer);
    console.log('Hello World!');
  }
}

init();
