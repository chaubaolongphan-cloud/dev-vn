Bài 19: Closures, Lexical Scope & Kỹ Thuật Memoization Tối Ưu Bộ Nhớ

psychology 1. Bản chất Lexical Scope & Vòng Đời Execution Context

Trong JavaScript, một Closure được tạo ra mỗi khi một hàm được khai báo bên trong một hàm khác, cho phép hàm con truy cập vào Lexical Environment (môi trường từ vựng) của hàm cha ngay cả khi hàm cha đã hoàn tất việc thực thi và thoát khỏi Call Stack.

Ở góc độ V8 Engine, thông thường các biến cục bộ nguyên thủy (primitive values) nằm trên Stack. Tuy nhiên, khi một biến được "đóng gói" (closed over) bởi một hàm con lồng bên trong, V8 sẽ đẩy toàn bộ Context đó lên Heap Memory để tránh việc bị bộ thu gom rác (Garbage Collector) dọn dẹp sớm.

// Kiến trúc V8 Heap Allocation khi sinh ra Closure
javascript memoization-engine.js 
// 1. Triển khai Higher-Order Memoize Function với Closure bảo toàn bộ nhớ
export function createMemoizer(targetFunction, resolver = JSON.stringify) {
  // Biến cache được đóng kín trong Heap Lexical Scope
  const cache = new Map();

  return function memoized(...args) {
    const key = resolver(args);

    if (cache.has(key)) {
      // Cache Hit: O(1) time complexity, tránh re-compute
      return { value: cache.get(key), isCached: true };
    }

    // Cache Miss: Thực thi hàm gốc nặng chi phí tính toán
    const computedResult = targetFunction.apply(this, args);
    cache.set(key, computedResult);

    return { value: computedResult, isCached: false };
  };
}

// 2. Thử nghiệm thực tế với thuật toán Fibonacci đệ quy
const heavyFibonacci = (n) => (n <= 1 ? n : heavyFibonacci(n - 1) + heavyFibonacci(n - 2));
const fastFib = createMemoizer(heavyFibonacci);

console.log(fastFib(40)); // Lần 1: isCached = false (~1200ms)
console.log(fastFib(40)); // Lần 2: isCached = true (<1ms)

Senior Caveat: Nguy cơ Memory Leaks qua Uncleaned Closures

Khi gắn Closure chứa tham chiếu tới các DOM nodes lớn vào các sự kiện toàn cục (window.addEventListener hoặc Pub/Sub managers) mà quên gỡ bỏ (removeEventListener), toàn bộ chuỗi Scope cha sẽ không bao giờ được GC giải phóng, dẫn tới hiện tượng Detached DOM Nodes Leak cực kỳ phổ biến trong các ứng dụng SPA phức tạp.
