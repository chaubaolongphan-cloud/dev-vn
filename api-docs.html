Tài liệu API

Chào mừng bạn đến với tài liệu API của DevPortal VN. Giao diện lập trình ứng dụng (API) của chúng tôi được thiết kế theo chuẩn RESTful, trả về định dạng JSON và sử dụng các mã trạng thái HTTP tiêu chuẩn. Hướng dẫn này sẽ giúp bạn tích hợp hệ thống của mình với nền tảng một cách nhanh chóng và an toàn.

Lấy danh sách ngôn ngữ GET

/v1/languages

Endpoint này cho phép bạn truy xuất danh sách các ngôn ngữ lập trình được hỗ trợ trên nền tảng, bao gồm siêu dữ liệu và trạng thái khả dụng.

Parameters

Name Type Description
limit integer (query) Số lượng kết quả trả về tối đa (Mặc định: 20)
offset integer (query) Vị trí bắt đầu của tập kết quả (Phân trang)
status string (query) Lọc theo trạng thái active hoặc deprecated

Response Example

200 OK JSON 

{
  "data": [
    {
      "id": "lang_01",
      "name": "JavaScript",
      "version": "ES2022",
      "is_active": true
    },
    {
      "id": "lang_02",
      "name": "Python",
      "version": "3.11",
      "is_active": true
    }
  ],
  "pagination": {
    "total": 42,
    "limit": 20,
    "offset": 0
  }
}
